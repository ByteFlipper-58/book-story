# Traductor incorporado

EverBook ahora puede traducir textos seleccionados y libros completos directamente en el lector.

- Se agregó traducción en la aplicación con traducción sin conexión Google Translate y ML Kit donde esté disponible
- El texto seleccionado se abre en una hoja inferior de traducción con alternancia de original/traducción, copia y acciones de aplicaciones externas.
- La traducción de todo el libro se ejecuta en segundo plano, almacena en caché los resultados y muestra el texto traducido progresivamente mientras continúa el trabajo.
- Se agregaron controles de idioma de origen y de destino, administración de modelos fuera de línea, descargas exclusivas de Wi-Fi y valores predeterminados de idioma del dispositivo.
- Se agregaron notificaciones de progreso con acciones de pausa, reanudación y cancelación para traducciones de libros largos.
- Manejo mejorado del límite de velocidad de Google, comportamiento de reintento y retroceso, y estilo de traducción en línea

# Lectura de estadísticas

Una nueva pantalla de Estadísticas ayuda a realizar un seguimiento de los hábitos de lectura en libros de texto y PDF.

- Las sesiones de lectura se registran desde el lector de texto y el lector PDF con limitación de tiempo de inactividad.
- Se agregaron gráficos para actividad, hora del día, mapa de calor, objetivos y clasificaciones por libro.
- Los desgloses de actividades muestran rangos de días, semanas, meses, tres meses y años con listas de libros detalladas.
- El panel de métricas se puede personalizar, reordenar, restablecer y ajustar con un objetivo semanal personalizado.
- Los datos estadísticos se limpian cuando se eliminan los libros

# Almacenar compilaciones y actualizaciones

EverBook ahora tiene flujos de distribución separados para las versiones standalone, Play Store y RuStore.

- Se agregó una compilación RuStore dedicada con anuncios de Yandex, RuStore Remote Config, actualizaciones en la aplicación y mensajes de revisión.
- Las compilaciones Play Store y RuStore pueden comenzar a actualizar y revisar los flujos después de los umbrales de incorporación y uso del lector.
- La compilación standalone EverBook puede verificar las versiones de GitHub para obtener actualizaciones.
- La pantalla Acerca de ahora incluye verificaciones de actualización manuales, estado de carga, hoja de actualización y entrada de revisión de licencias.

# Biblioteca más inteligente

La biblioteca ahora reacciona al progreso del lector de texto y realiza menos trabajo innecesario al actualizarse.

- Los libros abiertos en el lector de texto pasan a Lectura, y los libros terminados pasan a Ya leídos
- El mantenimiento diario mueve los libros obsoletos de Lectura a Descartados si no se abrieron durante siete o más días
- La biblioteca carga categorías y últimos tiempos de apertura en lote para evitar consultas Room repetidas
- Los guardados de desplazamiento del lector de texto ya no activan recargas frecuentes de la biblioteca y el historial
- La carga de portadas, sombreados y pestañas vecinas se almacena en caché o se precompone para una paginación más fluida
- Las categorías predeterminadas ya no se pueden eliminar con un gesto de deslizar la configuración

# Incorporación, localización y correcciones

Esta versión también pule el primer lanzamiento, las traducciones y la estabilidad.

- La incorporación ahora incluye un paso de permiso de notificación que explica las notificaciones de actualización, traducción y descarga del modelo ML.
