# Nouveau traitement du texte

Le lecteur utilise un nouveau système de traitement : le texte du livre est préparé par parties et devient disponible au fur et à mesure

- Les premières parties du livre apparaissent plus tôt, sans attendre le traitement complet du fichier
- Le texte préparé est enregistré, ce qui rend la réouverture du même livre plus rapide
- Les paramètres ajoutent une préparation expérimentale en arrière-plan : les nouveaux livres peuvent être préparés à l'avance pour la lecture

---

# Vue PDF native

Les PDF peuvent s'ouvrir en vue native, en conservant les pages du document

- Un mode d'affichage PDF natif a été ajouté
- Le mode PDF par défaut peut être choisi dans les paramètres
- Des réglages pour les pages, le zoom, les couleurs et le comportement de l'écran ont été ajoutés
- La position dans un PDF est enregistrée séparément

---

# Importer des livres depuis Android

Les livres peuvent être ajoutés à EverBook directement depuis d'autres apps

- Les fichiers peuvent être envoyés avec Ouvrir avec ou Partager
- Fonctionne avec Telegram, les gestionnaires de fichiers, les navigateurs et d'autres apps
- Les livres importés sont enregistrés dans EverBook
- Un livre s'ouvre immédiatement, plusieurs livres vont vers l'écran d'ajout

---

# Accès rapide depuis l'historique

Depuis l'historique, il est possible de revenir plus vite au dernier livre disponible

- Le premier appui ouvre l'historique
- Le second appui ouvre le dernier livre disponible
- Si aucun livre adapté n'est disponible, l'app reste sur l'écran actuel
