# Notes et surlignages

- Sélectionnez un passage dans le texte original pour ouvrir le menu des annotations
- Choisissez une couleur dans la palette pour surligner une idée importante, ajoutez un marque-page ou rédigez une note sur le passage
- Ouvrez « Annotations » dans le lecteur pour voir tous les éléments enregistrés et filtrer les marque-pages, surlignages ou notes
- Touchez l’annotation souhaitée pour revenir à son emplacement dans le livre ; vous pouvez la modifier ou la supprimer

---

# Défilement automatique

- Touchez n’importe où sur l’écran pour afficher les barres supérieure et inférieure, puis touchez « Défilement automatique » dans la barre inférieure pour ouvrir les commandes de vitesse
- Le panneau permet de ralentir ou d’accélérer le défilement, de choisir une vitesse de 1× à 10× et de mettre la lecture en pause si nécessaire
- Après quelques secondes, le panneau se replie en une puce compacte afin de ne pas masquer le texte ; touchez la puce pour redéployer les commandes de vitesse
- Dans les réglages du lecteur, vous pouvez choisir la position et la transparence de la puce, et y ajouter un bouton de pause pour arrêter rapidement le défilement automatique

# Luminosité par geste

- Ouvrez les réglages du lecteur et activez « Luminosité personnalisée » pour activer le geste
- Pendant la lecture, faites glisser verticalement près du bord gauche ou droit de l’écran : vers le haut pour plus de luminosité, vers le bas pour moins de luminosité
- Le geste ne fonctionne que sur les bords, laissant le centre de l’écran libre pour lire, sélectionner du texte et faire défiler normalement
- Désactivez la luminosité personnalisée dans les réglages pour revenir au niveau de luminosité du système

---

# Polices personnalisées

- Importez des fichiers TTF et OTF et utilisez-les dans le lecteur
- Après l’importation, choisissez la police souhaitée dans la liste
- Supprimez de la liste les polices dont vous n’avez plus besoin

- Toutes les icônes de l’application ont été mises à jour : des Material Symbols arrondis sont désormais utilisés
- Le téléchargement des modèles de langue et le mode « Wi‑Fi uniquement » ont été améliorés
- Les langues de traduction par défaut sont désormais choisies en tenant compte de la langue de l’appareil
- L’infrastructure publicitaire a été unifiée : AdMob est maintenant le fournisseur principal pour Play Store et RuStore
- Les publicités de Yandex Ads et Unity Ads sont diffusées via la médiation AdMob
