# 笔记和高亮

- 在原文中选中一段文字，即会显示用于处理注释的菜单
- 从调色板中选择颜色以高亮重要内容、添加书签或为该段文字写笔记
- 在阅读器中打开「注释」，即可查看所有已保存的项目，并筛选书签、高亮或笔记
- 点按所需注释即可回到书中的相应位置；还可以编辑或删除它

# 自动滚动

- 点按屏幕任意位置以显示顶部和底部栏，然后点按底部栏中的「自动滚动」以打开速度控制
- 可在面板中减慢或加快滚动速度，选择 1× 到 10× 的速度，并在需要时暂停阅读
- 几秒后，面板会收起为紧凑的浮动按钮，以免遮挡文字；点按该按钮可再次展开速度控制
- 可在阅读器设置中选择该按钮的位置和透明度，并添加暂停按钮以快速停止自动滚动

---

# 手势调节亮度

- 打开阅读器设置并启用「自定义亮度」以启用此手势
- 阅读时，在屏幕左侧或右侧边缘附近垂直滑动：向上更亮，向下更暗
- 该手势仅在边缘区域生效，因此屏幕中央可用于阅读、选择文字和正常滚动
- 在设置中关闭自定义亮度，即可恢复使用系统亮度级别

---

# 自定义字体

- 导入 TTF 和 OTF 文件并在阅读器中使用
- 导入后，从列表中选择所需的字体
- 从列表中删除不再需要的字体
