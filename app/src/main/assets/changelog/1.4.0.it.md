# Nuova elaborazione del testo

Il lettore usa un nuovo sistema di elaborazione: il testo del libro viene preparato a parti e diventa disponibile man mano

- Le prime parti del libro appaiono prima, senza attendere l'elaborazione completa del file
- Il testo preparato viene salvato, quindi riaprire lo stesso libro è più veloce
- Nelle impostazioni c'è una preparazione sperimentale in background: i nuovi libri possono essere preparati in anticipo per la lettura

---

# Vista PDF nativa

I PDF possono aprirsi in vista nativa, mantenendo le pagine del documento

- È stata aggiunta una modalità di visualizzazione PDF nativa
- La modalità PDF predefinita può essere scelta nelle impostazioni
- Sono state aggiunte impostazioni per pagine, zoom, colori e comportamento dello schermo
- La posizione nei PDF viene salvata separatamente

---

# Importare libri da Android

I libri possono essere aggiunti a EverBook direttamente da altre app

- I file possono essere inviati con Apri con o Condividi
- Funziona con Telegram, file manager, browser e altre app
- I libri importati vengono salvati in EverBook
- Un libro si apre subito, più libri passano alla schermata di aggiunta
