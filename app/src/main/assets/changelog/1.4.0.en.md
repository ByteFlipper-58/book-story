# New text processing

The reader now uses a new processing system: book text is prepared in parts and becomes available as it is ready

- The first parts of a book appear sooner, without waiting for the whole file to finish processing
- Prepared text is saved, so reopening the same book is faster
- Settings now include experimental background preparation: newly added books can be prepared for reading ahead of time

---

# Native PDF view

PDF files can open in native view, keeping the document pages intact

- Added a native PDF viewing mode
- The default PDF mode can be selected in settings
- Added controls for pages, zoom, colors and screen behavior
- PDF position is saved separately

---

# Import books from Android

Books can be added to EverBook directly from other apps

- Files can be sent with Open with or Share
- Works with Telegram, file managers, browsers and other apps
- Imported books are saved in EverBook
- One book opens immediately, while several books go to the add-books screen

---

# Quick history jump

History can open the latest available book more quickly

- First tap opens History
- Second tap opens the latest available book
- If no suitable book is available, the app stays on the current screen
