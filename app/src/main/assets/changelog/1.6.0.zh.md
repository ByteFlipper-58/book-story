# 内置翻译器

EverBook 现在可以直接在阅读器中翻译选定的文本和整本书。

- 添加了应用内翻译，包括 Google Translate 和 ML Kit 离线翻译（如果可用）
- 选定的文本在翻译底部工作表中打开，其中包含原始/翻译切换、复制和外部应用程序操作
- 全书翻译在后台运行，缓存结果并在工作继续的同时逐步显示翻译文本
- 添加了源语言和目标语言控制、离线模型管理、仅 Wi-Fi 下载和设备语言默认值
- 为长篇书籍翻译添加了带有暂停、恢复和取消操作的进度通知
- 改进了 Google 速率限制处理、重试和退避行为以及内联翻译样式

# 阅读统计

新的统计屏幕有助于跟踪教科书和 PDF 的阅读习惯。

- 阅读会话由文本阅读器和 PDF 阅读器记录，并具有空闲时间上限
- 添加了活动、一天中的时间、热图、目标和每本书排名的图表
- 活动细分显示日、周、月、三个月和一年的范围以及详细的图书列表
- 指标面板可以根据自定义的每周目标进行自定义、重新排序、重置和调整
- 删除书籍时统计数据也会被清除

# 商店构建和更新

EverBook 现在为 standalone、Play Store 和 RuStore 构建提供单独的分发流程。

- 添加了专用的 RuStore 版本，其中包含 Yandex 广告、RuStore Remote Config、应用内更新和审核提示
- Play Store 和 RuStore 版本可以在入职和读者使用阈值后开始更新和审核流程
- standalone EverBook 版本可以检查 GitHub 版本的更新
- “关于”屏幕现在包括手动更新检查、加载状态、更新表和离开审核条目

# 智慧图书馆

书库现在会根据文本阅读器中的进度更新状态，并在刷新时减少不必要的工作。

- 在文本阅读器中打开的书籍会移到“正在阅读”，读完的书籍会移到“已读”
- 每日维护会把七天或更久未打开的“正在阅读”书籍移到“已放弃”
- 书库刷新会批量加载分类和最后打开时间，避免重复的 Room 查询
- 文本阅读器的滚动保存不再频繁触发书库和历史记录重新加载
- 封面、遮罩和相邻标签页会被缓存或预先组合，让翻页更流畅
- 无法再通过设置滑动手势删除默认类别

# 入职、本地化和修复

此版本还完善了首次发布、翻译和稳定性。

- 入职现在包括一个通知权限步骤，用于解释更新、翻译和 ML 模型下载通知
- 隐私政策渲染现在共享在应用程序中使用的相同 themed HTML view
- 品牌资产得到更新，包括专用的夜间模式版本
