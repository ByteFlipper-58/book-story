# Nuevo procesamiento de texto

El lector tiene un nuevo sistema de procesamiento: el texto del libro se prepara por partes y aparece a medida que está listo

- Las primeras partes del libro aparecen antes, sin esperar a que se procese todo el archivo
- El texto preparado se guarda, por eso volver a abrir el mismo libro es más rápido
- En los ajustes aparece una preparación experimental en segundo plano: los libros nuevos pueden prepararse por adelantado para la lectura

---

# Vista PDF nativa

Los PDF pueden abrirse en vista nativa, manteniendo las páginas del documento

- Se añadió un modo de visualización PDF nativo
- Se puede elegir el modo PDF predeterminado en los ajustes
- Se añadieron ajustes de páginas, zoom, colores y comportamiento de pantalla
- La posición en PDF se guarda por separado

---

# Importar libros desde Android

Los libros pueden añadirse a EverBook directamente desde otras apps

- Los archivos pueden enviarse con Abrir con o Compartir
- Funciona con Telegram, gestores de archivos, navegadores y otras apps
- Los libros importados se guardan en EverBook
- Un libro se abre al instante, varios libros pasan a la pantalla de añadido

---

# Salto rápido desde el historial

Desde el Historial se puede volver más rápido al último libro disponible

- El primer toque abre el Historial
- El segundo toque abre el último libro disponible
- Si no hay un libro adecuado, la app permanece en la pantalla actual
