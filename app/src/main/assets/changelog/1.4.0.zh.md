# 新的文本处理

阅读器采用了新的处理系统：书籍文本会分段准备，并在准备好后逐步显示

- 书籍的前几部分会更早出现，不必等待整个文件处理完成
- 已准备好的文本会被保存，因此再次打开同一本书会更快
- 设置中新增了实验性的后台准备：新添加的书籍可以提前为阅读做好准备

---

# 原生 PDF 视图

PDF 可以以原生视图打开，并保留文档页面

- 新增原生 PDF 查看模式
- 可以在设置中选择默认 PDF 模式
- 新增页面、缩放、颜色和屏幕行为设置
- PDF 阅读位置会单独保存

---

# 从 Android 导入书籍

可以直接从其他应用将书籍添加到 EverBook

- 文件可以通过打开方式或分享发送
- 支持 Telegram、文件管理器、浏览器和其他应用
- 导入的书籍会保存在 EverBook 中
- 一本书会立即打开，多本书会进入添加书籍页面

---

# 从历史快速跳转

可以从历史记录更快返回最近可用的书籍

- 第一次点击打开历史记录
- 第二次点击打开最近可用的书籍
- 如果没有合适的书籍，应用会停留在当前页面
