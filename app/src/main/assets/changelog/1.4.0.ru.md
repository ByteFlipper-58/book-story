# Новая обработка текста

Читалка получила новую систему обработки: текст книги подготавливается частями и становится доступен по мере готовности

- Первые части книги появляются раньше, без ожидания полной обработки всего файла
- Подготовленный текст сохраняется, поэтому повторное открытие проходит быстрее
- В настройках появилась экспериментальная фоновая подготовка: новые книги заранее готовятся для чтения

# Нативный вид PDF

PDF можно открывать в нативном виде, с сохранением страниц документа

- Добавлен режим просмотра PDF в нативном виде
- Можно выбрать режим PDF по умолчанию
- Добавлены настройки страниц, масштаба, цветов и поведения экрана
- Позиция в PDF сохраняется отдельно

# Импорт книг из Android

Книги можно добавлять в EverBook прямо из других приложений

- Файлы можно отправлять через Открыть с помощью или Поделиться
- Работает с Telegram, файловыми менеджерами, браузерами и другими приложениями
- Полученные книги сохраняются в EverBook
- Одна книга откроется сразу, а несколько книг попадут на экран добавления

---

# Быстрый переход из истории

В Истории можно быстрее вернуться к последней доступной книге

- Первое нажатие открывает экран Истории
- Повторное нажатие открывает последнюю доступную книгу
- Если подходящей книги нет, приложение остается на текущем экране
