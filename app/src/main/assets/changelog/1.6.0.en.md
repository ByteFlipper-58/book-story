# Built-in translator

EverBook can now translate selected text and whole books directly in the reader.

- Added in-app translation with Google Translate and ML Kit offline translation where available
- Selected text opens in a translation bottom sheet with original/translation toggle, copy and external app actions
- Whole-book translation runs in the background, caches results and shows translated text progressively while work continues
- Added source and target language controls, offline model management, Wi-Fi-only downloads and device-language defaults
- Added progress notifications with pause, resume and cancel actions for long book translations
- Improved Google rate-limit handling, retry and backoff behavior, and inline translation styling

---

# Reading statistics

A new Statistics screen helps track reading habits across text books and PDFs.

- Reading sessions are recorded from the text reader and the PDF reader with idle-time capping
- Added charts for activity, time of day, heatmap, goals and per-book rankings
- Activity drilldowns show day, week, month, three-month and year ranges with detailed book lists
- The metric panel can be customized, reordered, reset and tuned with a custom weekly goal
- Statistics data is cleaned up when books are deleted

# Store builds and updates

EverBook now has separate distribution flows for standalone, Play Store and RuStore builds.

- Added a dedicated RuStore build with Yandex ads, RuStore Remote Config, in-app updates and review prompts
- Play Store and RuStore builds can start update and review flows after onboarding and reader usage thresholds
- The standalone EverBook build can check GitHub releases for updates
- The About screen now includes manual update checks, loading state, update sheet and leave-review entry
- All builds now check for a new version in the background and show a notification when an update is available
- App notifications now run through a single, unified system for consistent behavior

---

# Smarter library

The library now reacts to text-reader progress and does less unnecessary work while refreshing.

- Books opened in the text reader move into Reading, and finished books move into Already read
- Daily maintenance moves stale Reading books that were untouched for seven or more days
- Library refreshes batch category and last-opened lookups to avoid repeated Room queries
- Text-reader scroll saves no longer trigger frequent library and history reloads
- Cover loading, scrims and neighboring tabs are cached or precomposed for smoother paging
- Default categories can no longer be deleted by a settings swipe gesture

---

# PDF reader

Large and scanned PDFs are handled more gracefully, and the reader is more stable.

- Large PDFs and image-only (scanned) PDFs now open in native PDF mode instead of being rejected on import
- PDFs load through a disk-backed temporary file to keep RAM usage bounded, with the text-extraction limit raised to 300 MB
- A clear "native PDF mode only" notice is shown when text mode is unavailable, instead of a generic error
- Fixed a reader crash and a switching loop between native PDF mode and parsed-text mode
